# Liquid Glass Cam 26 — V0.1

Prototype kamera Android 11 dengan UI glassmorphism terinspirasi Camera iOS 26.

Target: Android 11+ (API 30+). Package: `com.liquidglasscam26`.

## Build menjadi APK

### GitHub Actions (paling mudah)
1. Buat repository GitHub baru.
2. Upload seluruh isi folder project ini.
3. Buka tab **Actions** → workflow **Build Liquid Glass Cam 26** → **Run workflow**.
4. Setelah selesai, buka hasil workflow dan download artifact **LiquidGlassCam26-debug-apk**.
5. Ekstrak ZIP artifact, lalu install `app-debug.apk` di Vivo Y12s.

APK debug belum ditandatangani untuk Play Store, tetapi bisa dipasang manual dengan mengizinkan instalasi dari sumber tersebut.
